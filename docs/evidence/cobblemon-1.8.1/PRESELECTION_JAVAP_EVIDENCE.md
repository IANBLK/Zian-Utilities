## FishingSpawnerFactory

The bytecode exposes a mutable static list:

```text
private static java.util.List<kotlin.jvm.functions.Function1<
  FishingSpawnerFactory$Context,
  java.util.List<SpawningInfluence>>> positionInfluenceBuilders;
```

`getPositionInfluenceBuilders()` directly returns that backing list.

`buildPositionInfluences(Context)` reads `positionInfluenceBuilders`, converts it to a sequence, invokes every builder with the current context, flattens the returned influence lists, and returns a mutable list.

The factory's static initializer installs Cobblemon's built-in builders into the same list, including player-level, bucket-normalizing, and habitat influences. Therefore appending Zian Utilities' builder extends the existing influence chain rather than replacing the built-in builders.

This supports:

```java
FishingSpawnerFactory.INSTANCE.getPositionInfluenceBuilders().add(...)
```

as an extension point for fishing position influences in the inspected Cobblemon artifact.

## PokeSnackSpawnerFactory

The bytecode exposes:

```text
private static java.util.List<kotlin.jvm.functions.Function1<
  PokeSnackSpawnerFactory$Context,
  SpawningInfluence>> influenceBuilders;
```

`getInfluenceBuilders()` directly returns that backing list.

`create(Context)` iterates the list, invokes each builder with the current context, filters null results, creates the Poké Snack spawner, then calls `Spawner.getInfluences().addAll(...)` with the produced influences. It subsequently adds enabled Cobblemon spawn-rule components.

Therefore appending Zian Utilities' builder adds an influence to each newly created Poké Snack spawner and does not replace the built-in influence builders or enabled spawn-rule components.

This supports:

```java
PokeSnackSpawnerFactory.INSTANCE.getInfluenceBuilders().add(...)
```

for the inspected Cobblemon artifact.

## SpawningInfluence contract

The inspected interface contains:

```text
public default boolean affectSpawnable(
    SpawnDetail detail,
    SpawnablePosition spawnablePosition);
```

Its default implementation returns `true`.

It also separately exposes `affectWeight`, `affectAction`, `affectSpawn`, bucket-weight hooks, position hooks, and spawn injection hooks. Zian Utilities overrides only `affectSpawnable`; it does not alter weights, actions, bucket weights, positions, or injected spawn lists.

This matches the intended narrow behavior of `GenerationPreselectionFilter`: reject a locked-generation `SpawnDetail` from eligibility while leaving the rest of Cobblemon's selection mechanics untouched.

## Runtime corroboration

Repository runtime testing additionally observed direct `PRESELECTION decision=ALLOW/DENY` diagnostics for fishing/Poké Snack candidate evaluation and confirmed that blocked-generation candidates did not become final spawns. Existing source-specific PRE guards remain installed as defense-in-depth.
